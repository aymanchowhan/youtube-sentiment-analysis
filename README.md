# YouTube Comment Sentiment Analysis

This project analyzes sentiment of YouTube comments using NLP models.

## Technologies Used

- Python
- YouTube Data API
- VADER
- BERT
- RoBERTa
- Streamlit
- Flask
- MLflow
- Docker

## Features

- Collect YouTube comments
- Sentiment analysis
- Emotion detection
- Topic modeling
- Spam detection
- Interactive dashboard
